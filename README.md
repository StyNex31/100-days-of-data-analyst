# 100 Days of Data Analyst

Учебный проект: изучаю Python на практике через трекер личных финансов.

> Я только начинающий в программировании и аналитике данных. Пользуюсь помощью ИИ как ментором/учителем, но стараюсь писать код и разбираться в логике самостоятельно.

## Что умеет трекер сейчас
- Хранит траты как список словарей (категория, сумма, дата)
- Консольное меню с выбором действий
- Добавление одной траты через input()
- Добавление нескольких трат подряд для одной категории/даты
- Подсчёт суммы трат по конкретной категории
- Классификация трат по уровням (мелкая / обычная / крупная) со статистикой количества

## Известные ограничения (пока не реализовано)
- Данные не сохраняются между запусками программы (нет работы с файлами)
- Нет проверки некорректного ввода (например, если ввести не число)

## Технологии
Python: переменные, списки, словари, циклы (for, while), условия (if/elif/else), функции, input()

## План развития
Сохранение в файл (CSV) → SQL → pandas → визуализация → BI-дашборд
